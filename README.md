# KindleNotes — заметки для Kindle Keyboard (Kindle 3, Wi-Fi)

Обновление-«прошивка» для Kindle Keyboard (модель k3w, только Wi-Fi), которое
добавляет на устройство удобные заметки: быстрый ввод, список, правка, поиск,
удаление и экспорт заметки в библиотеку Kindle.

Технически это не замена прошивки Amazon, а стандартный пакет обновления
`update_*.bin` (формат OTA V1 / FC02), который ставится через
**Settings → Menu → Update Your Kindle** и добавляет в систему маленький
сервис. Заметки открываются во встроенном браузере Kindle по адресу
`127.0.0.1:8080`. Полная прошивка при этом не трогается, и всё удаляется
вторым пакетом.

Готовые файлы лежат в [`dist/`](dist/):

| Файл | Назначение |
|---|---|
| `update_kindlenotes_1.0.0_k3w_install.bin` | установка / обновление |
| `update_kindlenotes_1.0.0_k3w_uninstall.bin` | удаление (заметки сохраняются) |

## Что требуется

1. **Kindle Keyboard Wi-Fi (Kindle 3, k3w)** с прошивкой 3.x.
   Для 3G-версий (k3g, k3gb) пакет нужно пересобрать с `DEVICE=k3g` или
   `DEVICE=k3gb` (см. «Сборка»), иначе Kindle откажется его ставить.
2. **Джейлбрейк** для Kindle 3 (пакет `kindle-jailbreak` с MobileRead).
   Без него Kindle принимает только обновления, подписанные Amazon.
   Сам джейлбрейк ставится так же, через «Update Your Kindle», один раз.

## Установка

1. Подключите Kindle к компьютеру по USB.
2. Скопируйте `dist/update_kindlenotes_1.0.0_k3w_install.bin` в **корень**
   диска Kindle (рядом с папкой `documents`).
3. Безопасно отключите Kindle.
4. На Kindle: **Home → Menu → Settings → Menu → Update Your Kindle**.
   Пункт активен, только если файл лежит в корне и джейлбрейк установлен.
5. Kindle перезагрузится. Через ~20 секунд после загрузки сервис готов.

Открыть заметки: **Home → Menu → Experimental → Launch Browser**, в адресной
строке набрать `127.0.0.1:8080` (цифры на Kindle Keyboard вводятся через
`Alt` + верхний ряд букв). Затем **Menu → Bookmark this page** — дальше
страница открывается из закладок браузера одним нажатием.

Если браузер при запуске просит включить Wi-Fi — включите, интернет для
работы заметок не нужен, сервер локальный.

## Что умеет

* **Список заметок** — новые сверху, заголовок = первая строка, под ним дата и
  начало текста.
* **Быстрая заметка** — поле в одну строку прямо над списком: ввёл, нажал
  «Записать».
* **Новая / Изменить** — большое текстовое поле, «Сохранить» / «Отмена».
* **Поиск** по всем заметкам, без учёта регистра, включая кириллицу.
* **Удалить** — с подтверждением.
* **В библиотеку** — копирует заметку как `.txt` в `documents`, после чего
  она появляется среди книг Kindle (после перезагрузки или подключения USB).
  Имя файла транслитерируется: «Список покупок» → `Note Spisok pokupok (…).txt`.
* Заметки хранятся как обычные **UTF-8 `.txt`** в `/mnt/us/notes/data/` —
  видны и редактируются с компьютера по USB.
* Интерфейс сделан под e-ink: чёрные рамки, крупный шрифт, без JavaScript,
  всё управляется джойстиком.
* Пока Kindle подключён к компьютеру как диск, страница честно пишет
  «Хранилище недоступно» и продолжает работать после отключения.

## Настройки

Файл `/mnt/us/notes/config` (виден по USB как `notes/config`):

```sh
PORT=8080     # адрес страницы: http://127.0.0.1:8080/
LAN=0         # 1 = открыть доступ с других устройств в вашей Wi-Fi сети
UI_LANG=ru    # ru или en
```

После правки — перезагрузить Kindle.

## Родное приложение: киндлет KindleNotes

Вторая, «родная» версия заметок: Java-приложение (Kindlet, KDK 1.0), которое
появляется прямо на главном экране Kindle как обычный документ и работает без
браузера, с родной клавиатурой, джойстиком и клавишей Menu.

Файлы в [`dist/`](dist/), один и тот же код с разной подписью:

| Файл | Когда брать |
|---|---|
| `KindleNotes.azw2` | **сначала этот**: ключи MKK 2025 года, подпись SHA1 |
| `KindleNotes-sha256.azw2` | если первый не запустился: те же ключи, подпись SHA-256 (как у KUAL 2025) |
| `KindleNotes-oldkeys.azw2` | если Kindlet Kit ставился до апреля 2025: старые ключи 2010 года |

Три варианта нужны потому, что тестовый сертификат «Mobileread Kindlet Kit»
истёк 17.04.2025, после чего ключи перегенерировали. Какой из файлов
запустится, зависит от того, какая версия кита стоит на вашем Kindle.

**Требования:** джейлбрейк и Mobileread Kindlet Kit (MKK, он же «ключи
разработчика», ставится через «Update Your Kindle»). Если на Kindle уже
работает KUAL, всё нужное есть.

**Установка:** скопировать выбранный `.azw2` в папку `documents` на Kindle,
отключить USB. На главном экране появится пункт **KindleNotes**, открыть его
как книгу.

**Управление:**
- Список: новые заметки сверху, выбор джойстиком, листание клавишами
  Next Page / Prev Page. Клавиши Q..P (или 1..0) открывают строку 1..10
  текущей страницы. Первая строка списка — «+ Новая заметка».
- Поиск: поле вверху, ввести текст, Enter или кнопка «Поиск». Ищет по
  заголовку и телу без учёта регистра, кириллица тоже.
- Редактор: обычное текстовое поле Kindle, печатать сразу. Первая строка —
  заголовок. **Back** сохраняет и возвращает в список. **Menu**: сохранить,
  удалить (с подтверждением), в библиотеку, назад без сохранения.
- При выходе из приложения или уходе в сон текст сохраняется автоматически.

**Где лежат заметки.** Приложение сначала пробует общую папку
`/mnt/us/notes/data`, то есть те же файлы, что у браузерной версии: тогда обе
версии видят одни и те же заметки. Если песочница киндлета не пускает туда,
заметки хранятся в папке приложения (`documents/KindleNotes.azw2`-данные),
«О программе» в меню показывает, какой вариант сработал. Лог ошибок:
`kindlenotes.log` в той же папке.

**Шрифты.** Если на вашей прошивке кириллица в интерфейсе приложения
выглядит квадратиками или наоборот слишком «техническим» шрифтом, положите в
папку приложения файл `font.cfg` с одним словом: `default` (шрифт Kindle),
`code2000` (универсальный шрифт со всеми алфавитами) или `auto` (по умолчанию:
code2000 только для текста с нелатинскими буквами).

**Сборка:** `make kindlet` (нужен JDK 8: класс-файлы должны быть версии Java
1.4, иначе виртуальная машина Kindle их не загрузит), `make kindlet-test`
прогоняет 44 проверки хранилища и жизненного цикла на ПК. Исходники в
`kindlet/src`, заглушки KDK API в `kindlet/kdk-stubs` (только используемые
классы и методы), ключи в `kindlet/keys`.

**Что проверено, а что нет.** Код скомпилирован против сигнатур настоящего
KDK, байткод проверен на отсутствие API новее Java 1.4, подписи проверены
jarsigner. Запуск на настоящем Kindle не проверялся: на устройстве остаются
три риска, которые видно только там: примет ли MKK подпись (поэтому три
файла), пустит ли песочница в общую папку (есть запасной вариант) и как
именно KTextArea реагирует на клавиши Back и Menu. Если что-то не так,
пришлите `kindlenotes.log` и опишите, что на экране.

## Что ещё добавить: предложение

**Доступ к заметкам с ноутбука или телефона по Wi-Fi.** Это главный плюс
именно Wi-Fi-версии: тот же сервер уже умеет слушать не только `127.0.0.1`,
но и всю сеть. Поставьте `LAN=1` в конфиге, узнайте IP Kindle
(Settings → Menu → Device Info) и откройте `http://<ip-kindle>:8080/` в любом
браузере дома. Длинные заметки набираются на нормальной клавиатуре, а читать
их удобно на e-ink. Эта возможность уже реализована и выключена по умолчанию,
потому что пароля нет: включайте её только в домашней сети.

Другие варианты, если хочется ещё:

* **Чек-листы** — строки, начинающиеся с `[ ]`, показывать как пункты с
  галочками (покупки, дела).
* **Импорт выделений** — кнопка, которая разбирает `My Clippings.txt` и
  складывает цитаты из книги в отдельную заметку.
* **Заметка на заставке** — показывать последнюю заметку на экране сна
  (вместе с хаком заставок).

Напишите, что из этого нужно, и это можно добавить следующей версией.

## Удаление

Скопировать `update_kindlenotes_1.0.0_k3w_uninstall.bin` в корень Kindle и
запустить «Update Your Kindle». Удаляются сервис и программа; папка
`/mnt/us/notes/data` с заметками и файл `config` остаются.

## Как это устроено

```
payload/notes/bin/notesd        статический ARMv6-бинарник (musl, ~75 КБ):
                                 HTTP-сервер и весь интерфейс заметок
payload/notes/bin/notes.sh      helper: start|stop|status|open|log (для SSH)
payload/notes/config            настройки
rootfs/etc/kindlenotes/launch.sh лаунчер, живёт в корневой ФС
rootfs/etc/upstart/kindlenotes.conf автозапуск (upstart) после framework
package/install.sh              скрипт, который выполняет Kindle при обновлении
package/uninstall.sh            скрипт удаления
src/notesd.c                    исходник сервера (один файл, без зависимостей)
tests/run.sh                    сквозные тесты (37 проверок)
build.sh / Makefile             сборка и упаковка через KindleTool
```

Важная деталь: лаунчер копирует `notesd` в RAM (`/var/tmp`) и запускает его
с рабочим каталогом `/`. Демон не держит открытых файлов на `/mnt/us`, поэтому
USB-режим диска продолжает работать, пока сервис запущен.

Установщик пишет лог в `/mnt/us/notes/install.log`, сервер — в
`/var/tmp/kindlenotes/notesd.log`.

## Сборка из исходников

Нужны: `gcc`/`cc`, `python3` (для `pip install ziglang`) или `zig` в PATH,
[KindleTool](https://github.com/NiLuJe/KindleTool), для тестов ARM-сборки —
`qemu-user-static`.

```sh
pip install ziglang           # кросс-компилятор ARMv6/musl
make                          # dist/update_kindlenotes_<ver>_k3w_*.bin
make test                     # тесты на нативной сборке
make test-arm                 # те же тесты на ARM-бинарнике под qemu
DEVICE=k3g make               # пакет для Kindle 3 3G (US)
```

## Ограничения и честные оговорки

* Пакет собран и проверен **без реального Kindle под рукой**: сервер прогнан
  под эмулятором qemu-arm (ARMv6, статическая сборка под ядро 2.6.x),
  установщик и лаунчер — в имитации файловой системы Kindle с заглушками
  системных команд. Поведение самого Kindle (upstart, `mntroot`, браузер)
  основано на известном устройстве прошивки 3.x и практике хаков MobileRead.
  Если после установки страница не открывается, проверьте
  `/mnt/us/notes/install.log` и пришлите его — поправлю.
* Пакет ничего не меняет в прошивке Amazon, кроме добавления двух файлов в
  `/etc`; худший сценарий — сервис не стартует. Откат — пакет uninstall.
* Доступа по паролю нет, поэтому `LAN=1` — только для доверенной сети.
* Команда `notes.sh open` (авто-запуск браузера) экспериментальная; основной
  способ — закладка в браузере.
