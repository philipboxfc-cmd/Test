# Аккорды по функциям (Android APK)

Приложение слушает игру через микрофон и записывает аккорды функциональными обозначениями
в заданной тональности, например: `t53 s6 K64 D7 t53 ‖ автентический каданс`.

## Как пользоваться
1. **🎤 Сказать** — произнесите тональность («ре минор», «фа диез мажор», «си бемоль минор»)
   или нажмите **Вручную** и выберите тонику и лад.
2. **● Запись** — играйте аккорды, **■ Стоп** — закончить. Неверно распознанный аккорд можно удалить нажатием.
3. **+** — сохранить запись в историю, сразу ввести новую тональность голосом и снова нажать «Запись».

Обозначения: T/t, S/s, D, d, SII/sII, III, VI, VII, VIIн; обращения 53, 6, 64 и 7, 65, 43, 2;
K64 — кадансовый квартсекстаккорд; D7→S — побочная доминанта. Кадансы: автентический,
несовершенный, плагальный, прерванный, половинный.

## Где взять APK
Каждый push собирает APK в GitHub Actions (workflow «Build APK»): файл `akkordy.apk`
в релизе **apk-latest** (Releases) и в артефактах запуска.

## Локальная сборка
Нужны Node 20+, JDK 17 и Android SDK:
```
npm install
npm run android:init
npm run android:build   # android/app/build/outputs/apk/debug/app-debug.apk
```
Веб-версию можно открыть прямо из `www/index.html` в Chrome (голосовой ввод через Web Speech API).
