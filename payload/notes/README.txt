KindleNotes — заметки для Kindle Keyboard (Kindle 3 Wi-Fi)
===========================================================

Как открыть
-----------
Home -> Menu -> Experimental -> Launch Browser, в адресной строке набрать:

    127.0.0.1:8080

Добавьте страницу в закладки браузера (Menu -> Bookmark this page),
чтобы потом открывать её одним нажатием.

Что умеет
---------
* список заметок (новые сверху), заголовок = первая строка
* быстрая заметка в одну строку прямо со списка
* создание, правка, удаление с подтверждением
* поиск по всем заметкам (без учёта регистра, включая кириллицу)
* «В библиотеку» — копирует заметку как .txt в documents,
  и она появляется среди книг Kindle
* заметки — обычные .txt в /mnt/us/notes/data, видны по USB

Файлы
-----
/mnt/us/notes/data/      ваши заметки (UTF-8 .txt)
/mnt/us/notes/config     настройки (порт, доступ по Wi-Fi, язык)
/mnt/us/notes/bin/       программа и helper-скрипт notes.sh
/etc/kindlenotes/        лаунчер (в корневой ФС)
/etc/upstart/kindlenotes.conf  автозапуск

Если страница не открывается
----------------------------
1. Подождите ~20 секунд после включения.
2. Отключите Kindle от USB: пока он подключён как диск, хранилище
   недоступно и страница покажет «Хранилище недоступно».
3. Перезагрузите Kindle (Settings -> Menu -> Restart).
4. Лог: /var/tmp/kindlenotes/notesd.log и /mnt/us/notes/install.log

Удаление: пакет update_kindlenotes_*_uninstall.bin через
«Update Your Kindle». Заметки при этом не удаляются.
